# 盲道检测系统 (Blind Sidewalk Detection)

基于 OpenCV 的盲道（黄色 tactile paving）检测与识别系统，包含图形化界面，集图像预处理、盲道定位、分割及多种图像处理工具于一体。

## 功能特性

- **盲道定位**：基于 HSV 颜色空间 + 形态学处理，快速定位黄色盲道区域
- **盲道分割**：提取最大连通域，输出分割后的盲道图像
- **图像处理工具箱**：内置 8 类图像处理方法，参数可实时调节
  - 灰度化
  - 对比度调整
  - 去噪（高斯模糊 / 中值滤波 / 双边滤波）
  - 边缘检测（Canny / Sobel / Laplacian）
  - 灰度拉伸（线性 / 对数 / 幂律）
  - 形态学处理（腐蚀 / 膨胀 / 开运算 / 闭运算 / 形态学梯度）
  - 二值化
- **GUI 界面**：Tkinter 图形界面，左侧控制面板 + 右侧双图对比
- **结果保存**：支持将处理后的图像保存为 png / jpg / bmp 格式

## 技术栈

- Python 3.x
- OpenCV (cv2)
- NumPy
- Pillow (PIL)
- Tkinter
- threading（多线程处理，避免界面卡顿）

## 使用方法

1. 运行程序：
   ```bash
   python blind_sidewalk_detection.py
   ```
2. 点击 **加载图像**，选择包含盲道的图片（支持 jpg / png / bmp / tif）
3. **盲道检测**：
   - 点击 **定位盲道**：自动检测并用绿色轮廓标出盲道区域（后台线程处理，界面不卡顿）
   - 点击 **盲道分割**：只保留盲道区域，其余部分置黑
4. **图像处理工具**：
   - 在「处理方法」下拉菜单中选择所需操作
   - 调节对应参数（对比度、核大小、阈值等）
   - 点击 **应用处理** 查看效果
5. 点击 **保存结果**，将当前处理后的图像保存到本地

## 检测算法流程

| 步骤 | 方法 | 说明 |
|------|------|------|
| 图像增强 | CLAHE + 双边滤波 | 提升对比度，保留边缘的同时降噪 |
| 颜色分割 | HSV 阈值 (H:15-35, S:40-255, V:120-255) | 提取黄色盲道区域 |
| 形态学优化 | 闭运算 + 开运算 + 膨胀（椭圆核 7×7） | 弥合缝隙、去除噪点、连通区域 |
| 连通域筛选 | 最大连通域提取 | 保留面积最大的区域作为盲道 |
| 特征可视化 | Canny 边缘 + 轮廓绘制 | 用绿色轮廓标注盲道边界 |

## 支持的图像处理方法

| 类别 | 方法 | 可调参数 |
|------|------|----------|
| 基础操作 | 原始图像、灰度化、二值化 | — |
| 对比度 | 对比度调整 | 0% ~ 200% |
| 去噪 | 高斯模糊 / 中值滤波 / 双边滤波 | 核大小 3~15 |
| 边缘检测 | Canny / Sobel / Laplacian | Canny 双阈值 |
| 灰度拉伸 | 线性 / 对数 / 幂律 | 参数 0.1~5.0 |
| 形态学 | 腐蚀 / 膨胀 / 开 / 闭 / 梯度 | 核大小 + 迭代次数 |

## 注意事项

- 目前针对**黄色盲道**进行检测，其他颜色盲道需调整 HSV 阈值
- 盲道区域在图像中应占一定比例，过小或过远可能影响检测效果
- 光照条件对检测结果有一定影响，建议使用光照均匀的图像
- 可根据实际场景修改代码中 `lower_hsv` 和 `upper_hsv` 的颜色范围
